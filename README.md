
# 🍽️ Foodies Restaurant Website

A responsive restaurant website built using HTML, CSS, and JavaScript.

## 📌 About The Project

Foodies Restaurant is a frontend web development project that allows customers to explore food items, add products to their shopping cart, and place demo orders.

## ✨ Features

- Responsive website design
- Home and food menu sections
- Food image gallery
- Add to Cart functionality
- Remove items from cart
- Automatic cart total calculation
- Cart data saved using Local Storage
- Customer checkout form
- Demo order confirmation
- Customer reviews section
- Contact form with validation
- My Orders section (order history interface)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How To Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## ⚠️ Project Status

This is a frontend demonstration project.

- Orders are not sent to a real restaurant.
- No backend or database is connected.
- Online payments are not implemented.
- Order history is planned for a future update.
